# Aurora — research announcement page

A static, dependency-free editorial page (HTML/CSS/JS) modeled on the layout and motion patterns of modern AI research launch posts.

Open `index.html` in a browser, or serve the folder: `python3 -m http.server`.

Features: sticky blurred nav with dropdowns, reading-progress bar, light/dark/system theme, masked title reveal, canvas "video" hero with play/scrub/captions, scroll-reveal, TOC scrollspy, animated counters, animated SVG charts, tabbed benchmark bars with sliding pill, auto-advancing demo carousels (typing terminal + chat transcript), and a closing canvas scene. Respects `prefers-reduced-motion`.

All content and branding ("Lumen Labs", "Aurora") are placeholders — replace them with your own.
